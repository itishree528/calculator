# 🧮 Advanced Calculator

A responsive calculator built with HTML, CSS, and JavaScript.

## ✨ Features

- Basic arithmetic operations
- Modulo and decimal calculations
- Backspace and clear
- Keyboard support
- Calculation history
- LocalStorage
- Dark/Light mode
- Responsive design
- Error handling

HTML5 • CSS3 • JavaScript

## 🎯 Concepts Practiced

DOM Manipulation • Events • Functions • Arrays • Objects • LocalStorage • JSON
